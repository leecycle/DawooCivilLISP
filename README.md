# DawooCivilLISP

AutoCAD와 ZWCAD 2024에서 사용하는 토목 설계용 AutoLISP 도구 모음입니다.

## 지원 환경

- AutoCAD 2015~2024 (Windows)
- ZWCAD 2021~2024 (Windows)
- ZWCAD 2024

## 설치

1. [최신 릴리스](https://github.com/leecycle/DawooCivilLISP/releases/latest)에서 `DawooCivilLISP.1.0.1.zip`을 내려받습니다.
2. ZIP 압축을 풉니다.
3. `INSTALL_DawooCivilLISP.cmd`를 실행합니다.
4. AutoCAD 또는 ZWCAD를 다시 시작합니다.

기본 설치 폴더는 `C:\DAWOO\CivilLISP`입니다. 설치 및 업데이트 시 기존 설정은 유지하면서 신뢰할 수 있는 위치와 APPLOAD 시작세트가 자동 등록됩니다.

## 주요 명령

- `VV` - 거리 측정 및 누계
- `GST` - 선형 STA/NO 측점 조회
- `RC` - 선, 폴리선, 호, 스플라인 방향 반전
- `DWCHELP` - 도움말 열기
- `DWCVER` - 설치 버전 확인
- `DWCUPDATE` - 최신 버전 확인 및 업데이트

> 토목좌표 기본 단위: 도면거리 1 = 1 m
